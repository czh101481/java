## 一、设计目标

| 目标 | v0 实况 | v1 结果 |
|---|---|---|
| 挂机不碾压日活 | 挂机占煞气 52%、魔晶 65%、血玉 76% | 煞气 **26.8%**、魔晶 **38.3%**、血玉 66.3% |
| 「12 小时封顶」名副其实 | 12h 只是单次存量上限，一天收两次 = 24h | 新增**每日累计结算 12h 上限**，收两次不翻倍 |
| 血玉不再倒挂 | 日产约 9.7 玉，常规日耗 19 玉 | 稳定日产 12.29 玉，常规日耗 **10 玉**，净 +2.29 |
| 攒高阶功法可行 | 仙阶 2000 玉 ≈ 200 天以上 | 仙阶 **600 玉**，纯挂机 50 天 / 按净流入 74 天 |
| 长期倍率不失控 | 转世每世 +10%，无上限 | 封顶 **10 世**（最高 +100%） |

| 秘境 19 次（保底） | 350 | 152 | ≈ 5.82 | 机缘期望 2.91 次 × 2 玉 |
| **日活合计** | **655** | **387** | **≈ 6.11** | |
| **全服日总产出** | **895** | **627** | **≈ 18.11** | 稳定部分（不靠机缘）≈ 12.29 玉 |

秘境明细：低险 12 次（净 +10 煞 / 5 晶 / 12% 机缘）、中险 4 次（+20 / 8 / 18%）、
高险 3 次（+50 / 20 / 25%）；魔晶按 `max(5, 所得煞气/10)`。

**与 v0 对比**：煞气 1375 → 895（−34.9%）、魔晶 1107 → 627（−43.4%）、
血玉 12.74 → 18.11（**+42.1%**）。总修为增速放慢，但血玉从「供不起」变为「有结余」。

## 三、魔窟规则

| 项 | 值 | 位置 |
|---|---|---|
| 单次未收存量上限 | 12 小时 | `DenRule.CAP_HOURS` |
| **每日累计结算上限** | **12 小时** | `DenRule.DAILY_CAP_HOURS` |
| 记账列 | `collect_date` / `collected_sec` | `demon_den`（v1 新增） |
| 聚煞阵 | 2 × 等级 煞气/h → 满级 20/h | `DenRule.SHA_PER_HOUR` |
| 魔晶矿 | 2 × 等级 魔晶/h → 满级 20/h | `DenRule.COIN_PER_HOUR` |
| 血玉髓脉 | 100‰ × 等级/h → 满级 1 玉/h | `DenRule.JADE_MILLI_PER_HOUR` |
| 心魔折损 | ≥60 聚煞 ×0.8；≥80 ×0.6（只罚煞气） | `DenRule` |
| 开辟费 | 聚煞/矿各 30 魔晶；髓脉 2 血玉 + 凝煞境 | `DenRule` |
| 升级费 | 聚煞/矿 `30×L²` 魔晶（满级共 8550） | `UPGRADE_COIN_FACTOR` |
| 髓脉升级费 | `ceil(L²/4)` 血玉（满级共 **75**，v0 为 145） | `UPGRADE_JADE_HALF` |

> 每日封顶的语义：`computePending` 取 `min(实际经过, 单次存量上限, 当日剩余额度)`；
> `collect` 成功后把本次结算秒数累加进 `collected_sec`，跨日自动清零。
> 后台「回拨上次收取」会同时把当日额度重置为 0，便于演示与补发。

## 六、已知非稳态项（本版未强制修正，预算按「稳态」口径才成立）

1. **论道全库 20 题、每题终身只能答一次**；研读也是全库首次一次性。上表的
   100 煞 / 40 煞只在前期成立，长期稳态应扣除。
2. **道具只限「买」不限「用」**：可提前囤积后一天内用完（单次最多 99 件）。
3. **随机项**：参悟 12% 奇遇、虚妄天赋 25% 翻倍、秘境机缘 ×2，上表按期望计。
4. **后台通道**：修者名录可直接改 `exp`；魔窟后台「回拨」可重置当日额度重算。
5. **鬼市不是产出**：玩家间转账抽 5%，全服净额反而减少。

> 若要让长期曲线更平，下一步应把论道/研读改成「每日可重复、收益递减」，
> 并给道具使用加每日上限；本版只做数值与每日封顶，不动这两处逻辑。
