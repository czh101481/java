一、项目总览
----------------------------------------------------------------

- 前端：Vue 3 + Vite 5 + Vue Router + axios
- 后端：Spring Boot 3.4.5 + MyBatis-Plus 3.5.7 + MySQL 8
- 数据库：MySQL 服务名 MySQL84，账号 root / 123456，库名 demon_db，端口 3306
- 端口：前端 5173，后端 8081

两个项目是桌面的【同级兄弟目录】（共同父目录是桌面 C:\Users\czh10\Desktop）：
- 后端：C:\Users\czh10\Desktop\springBootTest
- 前端：C:\Users\czh10\Desktop\魔族修行登录-Vue项目

启动/暂停脚本与本文档都放在桌面根目录，用 %~dp0 + 相对子目录引用两个工程。

【首页背景特效层（2026-10-16「万法归宗」视觉升级）】
  在 .home 内最前面新增 <div class="fx">（aria-hidden，pointer-events:none），
  保留原有卡片布局与文字信息，只在背后叠加 5 层动效：
  1) 中心星盘 .fx-astrolabe：SVG（viewBox 0 0 600 600）同心圆环 + 24 条放射刻度
     （v-for rotate 生成）+ 两个六边形法阵 + 中心光点 .fx-core。
     双层反向缓转：.fx-spin-slow 72s 正向、.fx-spin-rev 48s 反向；光点 fxPulse 呼吸。
  2) 电光 .fx-arc：左右各一道 SVG 折线闪电（a1 粉 / a2 紫），
     用 stroke-dasharray + dashoffset 做「间歇闪现」（fxBolt 6s，b2 延迟 2.6s 错开）。
  3) 符文锁链 .fx-chain：左右垂落的符文节点（runes 数组 10 个），
     逐个 animationDelay 0.14s 递进，fxRune 上下浮动 + 明暗变化。
  4) 星尘 .fx-dust：48 个点，位置/大小/延迟/时长由 script 内 dust 数组一次性随机生成
     （避免每次渲染跳动），fxRise 缓慢上浮淡出。
  5) 光晕：radialGradient #fxCore 中心粉紫渐变，垫在星盘最底。

  层级关系（重要，改动时别破坏）：
  - .fx：position:fixed; inset:0; z-index:0 → 页面滚动时背景不动。
  - 内容 .ticker/.hero/.hot/.grid/.elite/.home-foot：position:relative; z-index:1，压在特效上。
  - .nav 本身是 sticky z-index:5，天然在最上层。
  → 卡片、搜索框、文字全部不受影响，点击也不会被拦截。
  ⚠️ 特效只加在 Home.vue（首页）；登录/注册页背景仍是 App.vue 原样，本次未改动。

三、必看坑点（下次别再踩）
----------------------------------------------------------------
0. 【打开方式坑 · 用户常踩】dist/index.html 不能双击用 file:// 打开！
   浏览器禁止 file 协议加载 ES module（<script type="module">），必然白屏
   （实测：file:// 打开 DOM 仅 427 字节、.portal 出现 0 次；http 打开 49KB 正常）。
   正确访问方式（三选一）：
   a) 开发态：http://localhost:5173 （先跑 启动.bat 或 npm run dev）
   b) 看构建产物：双击桌面「预览页面.bat」→ 起零依赖静态服务 → http://localhost:8080
      （实现：前端根目录 preview.cjs，纯 node 无依赖，SPA 回退 index.html）
   c) npm run preview（vite 内置，端口 4173，需要 node_modules）
   ⚠️ 8081 是后端接口端口，不是页面！访问 http://localhost:8081/ 看到的是项目
     遗留的 thymeleaf 测试页（Hello World），不是本项目界面。
   ⚠️ 已做兼容：vite.config.js base:'./' + router 改 createWebHashHistory()，
     静态服务/任意目录部署都不会因子路由刷新 404（file:// 仍不行，属浏览器限制）。

1. 【字符集致命坑】JDBC URL 里的 characterEncoding 必须是 UTF-8，
   不能写 utf8mb4！Connector/J 会抛 UnsupportedEncodingException: utf8mb4，
   导致一碰真实数据库查询就 HTTP 500。Connector/J 会自动把 UTF-8 映射成服务端 utf8mb4。
   ——已修：application.properties 中 jdbc:mysql://.../demon_db?...characterEncoding=UTF-8...

2. 【导入 SQL 字符集坑】用 mysql 命令行导入含中文的 SQL 必须加
   --default-character-set=utf8mb4，否则中文被存成乱码，
   按道号精确查询匹配不到（登录 401、重复注册不拦截）。
   ——启动.bat 已自动加该参数。

3. 【mvnw 缺失 jar】springBootTest 原本缺 .mvn/wrapper/maven-wrapper.jar，
   mvnw/mvnw.cmd 跑不起来。已下载补齐。启动.bat 优先用系统 mvn，失败才回退 mvnw。

4. 【每次开机环境重置】node_modules 与 target 会被清空；脚本不能依赖它们。
   启动.bat 会自己 `npm install` 和 `mvn package` 重建。
   （系统安装的 Maven / Node / JDK / MySQL / IDEA 不受影响，仍在 PATH。）

5. 【MySQL 服务需管理员】启动 MySQL 服务需要管理员权限，启动.bat 会自动请求提权。

6. 【改了文件 ≠ 生效】凡是「新增/修改 SQL」或「新增后端接口」的改动，写完代码后必须补跑
   完整链路才算完成：导入 SQL → 停掉旧后端进程 → mvn package → 重启 → curl 验证接口。
   ⚠️ 曾踩过：写了扩充数据+公告表的 SQL 和接口，但因工具故障没跑导入与打包，
   结果数据库里 demon_announcement 表根本不存在、后端仍是旧 jar，前端新板块拿不到数据。
   排查手法：先开库数行数确认数据，再 curl 接口确认返回，不要只看代码是否在。

四、接口契约（前端 ↔ 后端）
----------------------------------------------------------------
基底址：/api/auth
- POST /api/auth/login      body:{name,password} → {code,msg,data:{token,user}}
- POST /api/auth/register   body:{name,email,realm,password} → {code,msg}
- GET  /api/auth/me         header: Authorization: Bearer <token> → {code,msg,data:user}
- GET  /api/home/overview   （无需令牌）→ {code,msg,data:{artCount,trialCount,debateCount,codexCount, artFeatured[], trialFeatured[], debateFeatured[], codexFeatured[]}}
- GET  /api/home/search?kw=  （无需令牌）→ {code,msg,data:{keyword,total,groups:[{type,typeName,total,items:[{type,typeName,id,title,summary,extra}]}]}}
- GET  /api/home/announcements（无需令牌）→ {code,msg,data:[{id,title,content,level,createdAt}]}
        ↑ 魔门公告走马灯数据源，按 createdAt 倒序；level 取值：通告/警示/喜讯/秘辛
- GET  /api/home/highlights  （无需令牌）→ {code,msg,data:[SearchItemVO]}
        ↑ 热门修习：4 个模块各取最新 2 条混合（共 8 条）
- GET  /api/home/list?type=art&kw=  （无需令牌）→ {code,msg,data:[SearchItemVO]}
        ↑ 模块列表页：type 取 art/trial/debate/codex；kw 可选，非空时按关键字过滤；按 id 倒序
- GET  /api/home/detail?type=art&id=1（无需令牌）→ {code,msg,data:{type,typeName,id,title,summary,content,meta:[{label,value}]}}
        ↑ 内容详情页：功法取 content 正文，其余三类用 summary 充当正文；
          meta 属性表：art=门类/品阶/所需境界，trial=地域/所需境界/凶险，debate=论者，codex=卷册
          查不到时返回业务码 404（msg「魔渊之中并无此记载」），HTTP 仍是 200
说明：HTTP 状态码恒为 200，业务结果用响应体里的 code 字段（200/400/401/409）。
